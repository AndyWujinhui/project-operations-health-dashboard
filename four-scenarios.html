Project Operations 与 M365 & Power Apps 的整合

把项目交付工作从 Project Operations 延伸到 Teams 日常协作空间，让项目经理和成员在 Teams、Power Apps、SharePoint 和 Power BI 中完成查看、协作、文档和沟通。

Collaboration Teams Power Platform

Power BI report 嵌入 Teams

在项目 channel 中直接查看项目组合、项目健康度、预算消耗和风险问题，无需离开 Teams。

Power Apps 嵌入 Project Operations

把轻量项目工作台、健康度页面或客户定制操作作为内嵌体验提供给项目角色。

SharePoint 文档管理

项目启动后自动生成文档空间，沉淀合同、交付文档、会议纪要和验收材料。

1创建项目项目在 Project Operations 中激活，明确项目经理、客户、日期和预算。
2发布到 Teams生成项目 Team 或 Channel，项目经理成为 owner，项目成员成为 member。
3连接文档SharePoint 项目目录作为合同、交付物、验收文件的统一入口。
4嵌入应用Power BI 和 Power Apps 作为 Teams tab 或项目内嵌页面提供业务操作。
5Agent 协作Project Agent / Cowork 发布到 Teams，支持项目概览、提醒和自然语言查询。

客户讲解重点

  1. 客户不需要在多个系统之间来回切换，项目相关的沟通、文档、报表和操作都可以进入 Teams 工作流。
  2. Project Operations 仍然是项目主数据和交付管控核心，Teams 和 Power Platform 是面向日常协作的入口。
  3. 通过项目角色动态决定可见内容，项目经理、项目成员和非项目成员看到的体验不同。

项目健康度 Dashboard

用项目进度、预算与实际、风险和问题综合评价项目健康度，帮助管理层优先关注需要干预的项目，而不是只看单一状态字段。

Portfolio Health Budget Risk

进度健康度

结合计划开始/结束、进度百分比、关键任务和延期风险，识别交付节奏问题。

成本健康度

比较预算、预测、实际成本、剩余成本和费用趋势，判断是否可能超预算。

风险与问题健康度

将 active risks、active issues、change requests 纳入评分，避免只看进度和成本。

1采集项目数据读取 Project Operations 中项目、任务、预算、工时、费用、风险和问题。
2计算健康分按进度、预算、资源、审批、风险问题加权生成综合评分。
3分层管理按 On Track、At Risk、Off Track 生成管理层视图和项目优先级。
4钻取项目从 overview 进入 detail，查看每个项目的健康度构成和改进方向。

Project AI 能力

展示 Project Operations 与 Copilot、MCP、Agent/Cowork 组合后的项目智能能力，从生成项目计划到报告、预警和自动化业务操作。

AI Assisted Delivery Copilot Agent

标准 Copilot

在 Microsoft 365 和业务应用中总结项目沟通、生成会议纪要、提炼风险和行动项。

WBS generation

根据项目范围、合同内容和模板生成 WBS 建议，再通过 Project Operations 支持的方式落入计划。

项目报告生成

基于项目状态、任务、工时、费用、风险和问题生成周报、月报和管理层摘要。

项目风险预警

从进度偏差、预算消耗、审批积压和风险数量中识别潜在 off-track 项目。

Copilot Agent for Project

支持项目概览查询、工时/费用提交、项目创建和状态更新等面向角色的自然语言入口。

Cowork in Teams

把项目助手发布到 Teams，让项目团队直接在 channel 中协作和提问。

1询问项目概览项目经理在 Teams 中询问当前项目状态、预算、风险和本周重点。
2生成 WBS 建议根据项目范围生成安装、调试、培训、UAT、验收等计划建议。
3提交工时费用项目成员通过 Agent 提交或查询自己的工时、费用和审批状态。
4风险预警AI 根据健康度数据提示延误、超预算、资源不足和开放问题。
5生成报告自动生成客户周报、管理层摘要和下一步行动建议。

Demo 话术

  1. AI 不替代项目经理，而是把项目经理每天需要追踪、整理、催办和汇报的工作自动化。
  2. WBS 和排程数据需要通过 Project Operations 支持的界面或计划 API 更新，确保排程引擎一致性。
  3. Agent 可以按角色工作：项目经理看全局，成员看自己的任务、工时、费用和待办。

从 CRM 到 Project Operations 的项目闭环

展示项目型销售从 Lead 开始，经过 Opportunity、Quote、Project Contract，最终生成 Project，形成售前到交付的一条完整业务链路。

Lead to Project Sales Delivery
1Lead客户产生项目需求，例如采购两台 MD-Demo001 并包含安装调试。
2Opportunity销售识别项目机会，确认客户、预算、预计收入和交付范围。
3Quote报价包含产品、安装调试、培训、UAT 和交付服务。
4Project Contract报价赢单后生成项目合同和合同明细，成为交付和收入管理基础。
5Project交付项目生成，项目经理按合同范围进行计划、资源、成本和健康度管理。

Demo 项目

MD-Demo001 安装调试项目 - Contoso Pharma，包含两台设备、安装调试和培训验收。

金额链路

产品 240,000 CNY，安装调试 60,000 CNY，培训验收 20,000 CNY，总金额 320,000 CNY。

交付项目

项目预算 320,000，预测成本 305,000，当前状态 Active / Plan / Yellow。

可演示业务对象

售前对象

Lead、Opportunity 和 Quote 体现客户需求识别、项目型商机推进、产品与服务组合报价。

合同对象

Project Contract 承接报价赢单后的合同金额、合同明细、产品行和服务行，是交付与收入管理的起点。

交付对象

Project 继承合同范围，进入项目计划、资源、成本、风险、问题和健康度管理。

业务链路示意

LeadContoso Pharma 提出采购 2 台 MD-Demo001，并需要安装、调试、培训和验收支持。
Opportunity销售确认项目预算 320,000 CNY，形成医疗设备安装调试项目机会。
Quote报价包含产品 240,000、安装调试 60,000、培训验收 20,000。
ContractProject Contract 继承 Quote，总金额 320,000，并生成产品合同线与服务合同线。
Project生成 MD-Demo001 安装调试项目，预算 320,000，预测成本 305,000，进入交付管控。

建议客户 demo 顺序：CRM 到项目创建 -> M365 协作发布 -> 项目健康度管理 -> AI 和 Agent 自动化。
